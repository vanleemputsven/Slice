# Subscriptions list filters

## Why

The old control strip put every category as a pill and stacked three labeled segment groups in a nested card. That looked heavy and made the list harder to reach. Filtering should feel like a toolbar above the register, not a second page.

## What people actually need

Slice is about personal cost, shared plans, and upcoming charges. The toolbar matches that:

1. **Search** — find a name or provider quickly
2. **Category** — one select (not eight pills)
3. **Sort** — next payment, your monthly share, or name
4. **Sharing** — all / shared / not shared (product-specific)
5. **Due soon** — inside the reminder lead window (same horizon as the dashboard)
6. **Needs review** — only shown when at least one row is flagged

Clear appears when any filter is active so people can reset without hunting.

## Layout

One quiet toolbar: search + selects on the first row, relevance chips + count on the second. No nested cards around the filters.
